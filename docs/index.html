    How it works

    Only hashes go onchain. No amounts, holdings, symbols or text.

    1

    Fingerprint

    Each log entry is hashed with its own random salt (SHA-256), so a hash reveals nothing about what the entry says.

    2

    Anchor

    Every night, the new fingerprints are combined into one root and written to a minimal contract on Monad, which records the time it landed.

    3

    Verify

    Re-hash the log as it is now and compare. Change one character of an anchored entry, or delete one, and its batch stops matching.

    What this proves

    The log hasn't been edited, deleted from or backdated since each entry was anchored.

    What it doesn't

    That the decisions were good. It is tamper-evident, not tamper-proof: nothing stops an edit, but an edit can't go unnoticed.
